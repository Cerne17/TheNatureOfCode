# Exercise 01: Right-Skewed Random Walker

## Objective

Create a random walker that has a tendency to move to the right and down, rather than moving with equal probability in all directions.

## Description

A random walker is a simple algorithm that simulates a path consisting of a succession of random steps. In this exercise, the walker is biased so that it is more likely to move rightward and downward, creating a "right-down-skewed" path.

## Implementation Details

- The walker starts at the center of the canvas.
- At each step, the walker chooses a direction, but the probability is skewed so that right and down are favored.

## How to Run

Open `index.html` in your browser to see the random walker in action.
